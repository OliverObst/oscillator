EXPERIMENT NOTES

A shared whole-body oscillator.

The trained decoder combines a mean waveform and four variation waveforms. Each contains all 22 K1 joint angles and six root residuals, with three Fourier harmonics. A 4 → 32 → 32 → 4 context network supplies the mixture weights. Total: 2,328 learned parameters.

Inputs and outputs

Inputs are shared phase, forward and lateral velocity (m/s), yaw rate (rad/s), and full cycle period (seconds). Joint angles and the local root rotation vector use radians; root residual translation uses metres. The runtime advances phase, smooths the four mixture values with a development-selected 0.1 s time constant, and rate-limits cadence to 1 cycle Hz/s. The browser evaluates the exported checkpoint directly; no Python server is needed for playback.

Two playback modes

Compare clips uses observed cycle phase and context with the saved fitted planar path. The source and learned robots have constant display offsets of +0.55 and −0.55 m in world y; there is no pose-by-pose alignment. Excluded frames show only the source. Contact markers indicate source kinematic contact estimates, not a constraint applied to the learned robot.

Generate motion integrates commanded planar velocity and turning, advances the nominal clock, and smoothly evolves the mixture. Commands can change during playback. Contact correction, joint-limit clamping and physical tracking are not applied. Sliders allow exploration, including combinations poorly represented in the small training set.
